# Java Methods — Level 1: Method Fundamentals

### Q01 — Create a Method to Print a Message

Create a method named `greet()` that prints:

```text
Hello, Welcome to Java Methods!
```

Call the method from `main()`.

Example:

```text
Hello, Welcome to Java Methods!
```

### Q02 — Create a Method to Print Your Name

Example:

```text

```

### Q13 — Create Multiple Methods

Create three separate methods:

* `add()` — returns the sum of two numbers.
* `subtract()` — returns the difference of two numbers.
* `multiply()` — returns the product of two numbers.

Example:

```text
Enter first number = 20
Enter second number = 5

Sum = 25
Difference = 15
Product = 100
```

## Level 1 Complete

**15 Questions**

After completing Level 1, you should be comfortable with:

```text
Method creation
      ↓
Method calling
      ↓
Parameters
      ↓
void methods
      ↓
int return
      ↓
double return
      ↓
String return
      ↓
boolean return
      ↓
Multiple parameters
      ↓
Multiple methods
      ↓
Method calling another method
      ↓
Scanner + methods
```
