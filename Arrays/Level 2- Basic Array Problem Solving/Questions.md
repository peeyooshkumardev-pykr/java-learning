# 🟡 Java Arrays — Level 2: Basic Array Problem Solving

### Q01 — Find the Second Largest Element

Take an array from the user and find the second largest element.

**Example:**

```text
Enter N = 6
Enter elements:
10 40 25 80 60 30

Second largest = 60
```

### Q02 — Find the Second Smallest Element

Take an array from the user and find the second smallest element.

**Example:**

```text
Enter N = 6
Enter elements:
10 40 25 80 60 30

Second smallest = 25
```

### Q03 — Print All Unique Elements

Take an array from the user and print only the elements that occur exactly once.

**Example:**

```text
Enter N = 8
Enter elements:

Unique elements:
30 40 50 60
```

### Q17 — Find Sum of Elements at Even and Odd Indices Separately

**Example:**

```text

```

### Q18 — Find Largest and Smallest Element Along With Their Indices and Sum Between Them

Take an array and find the largest and smallest elements along with their respective indices. Then calculate the sum of all elements **strictly between their indices**.

**Example:**

```text
Enter N = 7
Enter elements:
10 20 5 30 40 8 15

Largest = 40
Largest index = 4

Smallest = 5
Smallest index = 2

Sum of elements between them = 30
```


### Q19 — Find the Position of a Given Element




### Q20 — Count Elements Greater Than the Maximum of Another Array

**Example:**

```text

```
