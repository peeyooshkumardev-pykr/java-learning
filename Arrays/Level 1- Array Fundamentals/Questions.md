# Java Arrays — Level 1: Array Fundamentals

### Q01 — Take Input and Print All Array Elements

Take an integer `N` from the user, create an array of size `N`, take all elements as input, and print the elements.

**Example:**

```text
Enter N = 5
Enter elements:

10 20 30 40 50
```
