# 🟠 Java Arrays — Level 3: Array Logic & Searching

### Q01 — Find the Missing Number from 1 to N

Take an array containing numbers from `1` to `N`, with one number missing. Find the missing number.

**Example:**

    Enter N = 6
    Enter elements:
    1 2 3 5 6

    Missing number = 4

---

### Q02 — Find the Repeated Element

Take an array containing numbers where one element is repeated. Find the repeated element.

**Example:**

    Enter N = 6
    Enter elements:
    10 20 30 40 30 50

    Repeated element = 30

---

### Q03 — Find All Missing Elements in a Range

Take an array of integers and a range from `1` to `N`. Find all numbers from the range that are missing from the array.

**Example:**

    Enter N = 8
    Enter elements:
    1 3 5 6 8

    Missing elements:
    2 4 7

---
