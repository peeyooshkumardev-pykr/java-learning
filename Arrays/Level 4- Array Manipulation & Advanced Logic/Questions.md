# 🔵 Java Arrays — Level 4: Array Manipulation & Advanced Logic

### Q01 — Reverse an Array Without Using Another Array

Take an array from the user and reverse the array in the same array without creating another array.

**Example:**

```text
Enter N = 5
Enter elements:
10 20 30 40 50

Array after reverse:
50 40 30 20 10
```

---

### Q02 — Rotate an Array One Position to the Left

Take an array and rotate all elements one position to the left.

**Example:**

```text
Enter N = 5
Enter elements:
10 20 30 40 50

After left rotation:
20 30 40 50 10
```

---

### Q03 — Rotate an Array One Position to the Right

Take an array and rotate all elements one position to the right.

**Example:**

```text
Enter N = 5
Enter elements:
10 20 30 40 50

After right rotation:
50 10 20 30 40
```

### Q06 — Move All Zeros to the End

Take an array and move all zero elements to the end while maintaining the order of non-zero elements.

**Example:**

```text
Enter N = 7
Enter elements:
0 10 0 20 30 0 40

After rearranging:
10 20 30 40 0 0 0
```

### Q07 — Move All Negative Elements to the Beginning

Take an array and move all negative elements to the beginning of the array.

**Example:**

```text
Enter N = 7

After rearranging:
-5 -8 -2 10 20 30 40
```

### Q08 — Merge Two Arrays

Take two arrays from the user and create a third array containing all elements of both arrays.

**Example:**

```text
Array 1:
10 20 30

Array 2:
40 50 60

Merged array:
10 20 30 40 50 60
```

---

### Q09 — Merge Two Sorted Arrays

Take two sorted arrays and merge them into a single sorted array without sorting the final array separately.

**Example:**

```text
Array 1:
10 30 50 70

Array 2:
20 40 60 80

Merged array:
10 20 30 40 50 60 70 80
```

Take an array and an element. Remove every occurrence of that element.

### Q13 — Rearrange Array in Maximum-Minimum Form

Given a sorted array, rearrange it so that the maximum element comes first, then the minimum, then the second maximum, then the second minimum, and so on.

**Example:**

```text
Array:
1 2 3 4 5 6

After rearranging:
6 1 5 2 4 3
```

---

### Q14 — Rearrange Positive and Negative Elements Alternately

Rearrange an array so that positive and negative elements appear alternately whenever possible.

**Example:**

```text
Array:
1 2 -3 -4 5 -6

After rearranging:
1 -3 2 -4 5 -6
```

### Q15 — Find the Frequency of Each Digit in an Array

Take an array containing integers and count how many times each digit from `0` to `9` occurs in all the numbers.

**Example:**

```text
Enter N = 3
Enter elements:
12 25 102

Digit frequencies:
0 = 1
1 = 2
2 = 3
5 = 1
```

### Q16 — Replace Each Element with the Greatest Element on Its Right

For every element, replace it with the greatest element appearing to its right. Replace the last element with `-1`.

**Example:**

```text
Array:
16 17 4 3 5 2

After replacement:
17 5 5 5 2 -1
```

---

### Q17 — Rearrange Array According to Index Positions

Take an array where every value is between `0` and `N-1`. Rearrange the array so that each element is placed at its corresponding index.

**Example:**

```text
Array:
2 0 4 1 3

After rearranging:
0 1 2 3 4
```

### Q18 — Find the Next Greater Element for Every Element

For every element, find the first element to its right that is greater than it. If no greater element exists, print `-1`.

**Example:**

```text
Array:
4 5 2 10 8

Next greater elements:
5 10 10 -1 -1
```

---

### Q19 — Rearrange an Array So That Even Numbers Are at Even Indices

Take an array containing an equal number of even and odd elements. Rearrange it so that even elements occupy even indices and odd elements occupy odd indices.

**Example:**

```text
Array:
3 2 1 4 5 6

After rearranging:
2 3 4 1 6 5
```

### Q20 — Find the Minimum Number of Swaps Required to Sort an Array

Take an array containing distinct elements and find the minimum number of swaps required to arrange it in ascending order.

**Example:**

```text
Array:
4 3 2 1

Minimum swaps required = 2
```
