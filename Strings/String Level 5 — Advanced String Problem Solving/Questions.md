# String Level 5 — Advanced String Manipulation

## Q01 — Remove All Vowels From a String

Given a string, remove all vowels from the string.

Example:

Input: programming

Output: prgrmmng


## Q02 — Capitalize the First Letter of Every Word

Given a sentence, convert the first character of every word to uppercase.

Example:

Input: java is easy to learn

Output: Java Is Easy To Learn


## Q03 — Find the Word With the Most Vowels

Given a sentence, find the word that contains the highest number of vowels.

Example:

Input: java programming education

Output: Word With Most Vowels = education


## Q04 — Find the Word With the Most Consonants

Given a sentence, find the word that contains the highest number of consonants.

Example:

Input: java programming code

Output: Word With Most Consonants = programming


## Q05 — Print Words That Start and End With the Same Character

Given a sentence, print every word whose first and last characters are the same.

Example:

Input: level java madam code radar

Output: level madam radar


## Q06 — Find the Longest Consecutive Character Sequence

Given a string, find the character that appears consecutively for the longest time.

Example:

Input: aaabbccccd

Output:
Character = c
Count = 4


## Q07 — Replace a Given Word in a Sentence

Given a sentence, a word to find, and a replacement word, replace every occurrence of the given word.

Example:

Input: Java is easy and Java is powerful
Find: Java
Replace: Python

Output: Python is easy and Python is powerful


## Q08 — Insert a Character at a Given Position

Given a string, a character, and an index, insert the character at that position.

Example:

Input: hello
Character: X
Position: 2

Output: heXllo


## Q09 — Print Each Word With Its Number of Vowels

Given a sentence, print every word along with the number of vowels it contains.

Example:

Input: Java is powerful

Output:
Java = 2
is = 1
powerful = 3


## Q10 — Compress Consecutive Characters

Given a string, replace consecutive repeated characters with the character followed by its count.

Example:

Input: aaabbccccd

Output: a3b2c4d1
