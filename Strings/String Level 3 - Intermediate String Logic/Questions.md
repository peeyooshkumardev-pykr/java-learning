# String Level 3 — Intermediate String Logic

## Q01 — Reverse Each Word in a String

Given a sentence, reverse each individual word while keeping the order of the words unchanged.

Example:

Input:
Java is easy

Output:
avaJ si ysae

---

## Q02 — Reverse the Order of Words

Given a sentence, reverse the order of the words without reversing the characters inside each word.

Example:

Input:
Java is easy

Output:
easy is Java

---

## Q03 — Remove Duplicate Characters

Given a string, remove duplicate characters and keep only the first occurrence of each character.

Example:

Input:
programming

Output:
progamin

---

## Q04 — Find the Most Frequent Character

Given a string, find the character that appears the maximum number of times.

Ignore spaces.

Example:

Input:
programming

Output:
Most Frequent Character = r
Frequency = 2

---

## Q05 — Find the Least Frequent Character

Given a string, find the character that appears the minimum number of times.

Ignore spaces.

Example:

Input:
programming

Output:
Least Frequent Character = p
Frequency = 1

---

## Q06 — Check Whether Two Strings Are Anagrams

Given two strings, check whether they contain the same characters with the same frequencies, regardless of their order.

Example:

Input:
String 1:
listen

String 2:
silent

Output:
Strings are Anagrams

---

## Q07 — Count Frequency of Every Character

Given a string, find and print the frequency of every character.

Each character should be printed only once.

Example:

Input:
banana

Output:
b = 1
a = 3
n = 2

---

## Q08 — Find the First Non-Repeating Character

Given a string, find the first character that appears exactly once.

Example:

Input:
swiss

Output:
First Non-Repeating Character = w

---

## Q09 — Find the First Repeating Character

Given a string, find the first character that appears more than once.

Example:

Input:
programming

Output:
First Repeating Character = r

---

## Q10 — Check Whether a String Contains Only Digits

Given a string, check whether every character in the string is a digit from 0 to 9.

Example:

Input:
123456

Output:
String contains only digits

Example:

Input:
1234A6

Output:
String does not contain only digits
