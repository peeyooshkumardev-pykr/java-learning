# String Level 1 — String Basics

## Q01 — Find the Length of a String

Given a string, find and print the total number of characters in the string.

The program should count spaces as characters.

### Example

**Input:**
HelloWorld

**Output:**
Length of String = 10

---

## Q02 — Print Each Character of a String

Given a string, print each character of the string on a separate line.

### Example

**Input:**
Hello

**Output:**
H
e
l
l
o

---

## Q03 — Find the Character at a Given Index

Given a string and an index, print the character present at that index.

### Example

**Input:**
Programming
4

**Output:**
Character at index 4 = r

---

## Q04 — Count Vowels in a String

Given a string, count and print the total number of vowels (a, e, i, o, u) present in the string.

The program should count both uppercase and lowercase vowels.

### Example

**Input:**
Education

**Output:**
Number of Vowels = 5

---

## Q05 — Count Consonants in a String

Given a string, count and print the total number of consonants present in the string.

Count both uppercase and lowercase letters. Ignore spaces, digits, and special characters.

### Example

**Input:**
Hello World 123

**Output:**
Number of Consonants = 7

---

## Q06 — Count Digits in a String

Given a string, count and print the total number of digits (0–9) present in the string.

Ignore letters, spaces, and special characters.

### Example

**Input:**
Java123 Hello45!

**Output:**
Number of Digits = 5

---

## Q07 — Count Spaces in a String

Given a string, count and print the total number of spaces present in the string.

### Example

**Input:**
Java is very easy

**Output:**
Number of Spaces = 3

---

## Q08 — Count Uppercase and Lowercase Characters

Given a string, count and print the total number of uppercase and lowercase letters in the string.

Ignore spaces, digits, and special characters.

### Example

**Input:**
Hello WORLD 123!

**Output:**
Uppercase Characters = 6
Lowercase Characters = 4

---

## Q09 — Convert a String to Uppercase

Given a string, convert all lowercase letters in the string to uppercase and print the resulting string.

Keep spaces, digits, and special characters unchanged.

### Example

**Input:**
Hello Java 123!

**Output:**
HELLO JAVA 123!

---

## Q10 — Convert a String to Lowercase

Given a string, convert all uppercase letters in the string to lowercase and print the resulting string.

Keep spaces, digits, and special characters unchanged.

### Example

**Input:**
JAVA Program 123!

**Output:**
java program 123!
