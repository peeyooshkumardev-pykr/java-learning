# String Level 4 — Practice Questions

## Q01 — Remove All Duplicate Characters

Given a string, remove duplicate characters while keeping the first occurrence.

Example:

Input:
programming

Output:
progamin


## Q02 — Check Whether a String Contains Duplicate Characters

Given a string, check whether any character appears more than once.

Example:

Input:
hello

Output:
String contains duplicate characters

Example:

Input:
abcde

Output:
String does not contain duplicate characters


## Q03 — Print Characters That Appear More Than Once

Given a string, print every character that appears more than once.

Each character should be printed only once.

Example:

Input:
programming

Output:
r = 2
g = 2
m = 2


## Q04 — Print Characters That Appear Exactly Once

Given a string, print every character whose frequency is exactly 1.

Example:

Input:
programming

Output:
p = 1
o = 1
a = 1
i = 1
n = 1


## Q05 — Find the Second Most Frequent Character

Given a string, find the character with the second-highest frequency.

Example:

Input:
banana

Output:
Second Most Frequent Character = n


## Q06 — Find the Longest Word in a Sentence

Given a sentence, find and print the longest word.

Example:

Input:
Java programming is interesting

Output:
Longest Word = programming


## Q07 — Find the Shortest Word in a Sentence

Given a sentence, find and print the shortest word.

Example:

Input:
Java programming is easy

Output:
Shortest Word = is


## Q08 — Reverse Each Word of a Sentence

Given a sentence, reverse every individual word while keeping the word order unchanged.

Example:

Input:
Java is easy

Output:
avaJ si ysae


## Q09 — Check Whether Two Strings Are Rotations

Given two strings, check whether one string is a rotation of the other.

Example:

String 1:
abcd

String 2:
cdab

Output:
Strings are Rotations


## Q10 — Find the Most Frequent Word

Given a sentence, find the word that appears the most number of times.

Example:

Input:
java is easy and java is powerful

Output:
Most Frequent Word = java
