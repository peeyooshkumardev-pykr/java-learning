# String Level 2 — Basic String Logic

## Q01 — Reverse a String

Given a string, reverse it and print the reversed string.

### Example

**Input:**
Hello

**Output:**
olleH

---

## Q02 — Check if a String is a Palindrome

Given a string, check whether it reads the same forward and backward.

### Example

**Input:**
madam

**Output:**
Palindrome String

---

## Q03 — Count the Occurrence of a Given Character

Given a string and a character, count how many times that character appears in the string.

The comparison should be case-sensitive.

### Example

**Input:**
Programming
Character:
m

**Output:**
Character m appears = 2 times

---

## Q04 — Find the First Occurrence of a Character

Given a string and a character, find and print the index of the first occurrence of that character.

If the character is not present, print an appropriate message.

### Example

**Input:**
Programming
Character:
g

**Output:**
First occurrence of g = index 3

---

## Q05 — Find the Last Occurrence of a Character

Given a string and a character, find and print the index of the last occurrence of that character.

If the character is not present, print an appropriate message.

### Example

**Input:**
Programming
Character:
g

**Output:**
Last occurrence of g = index 10

---

## Q06 — Remove All Spaces from a String

Given two strings, check whether they are equal or not.
